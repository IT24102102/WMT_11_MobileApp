📱 WMT_11_MobileApp

A cross-platform mobile application built using React Native with Expo Go, developed as part of the WMT 11 project. The app provides a smooth and responsive user experience with core features designed for real-world usability.

🚀 Features
Cross-platform mobile support (Android & iOS)
Smooth and responsive UI built with React Native
Expo Go support for easy development and testing
API integration for dynamic data handling
Real-time updates and state management
Optimized mobile performance
🛠️ Tech Stack
React Native
Expo Go
JavaScript (ES6+)
VS Code (Development Environment)

⚙️ Installation & Setup

Make sure you have Node.js and Expo CLI installed.

git clone https://github.com/Rohana03/WMT_11_MobileApp.git

cd WMT_11_MobileApp

npm install

npx expo start

Then scan the QR code using Expo Go app on your mobile.

📱 Running the App
Install Expo Go on your Android/iOS device
Run the project using npx expo start
Scan QR code from terminal/browser
App will open instantly on your device
👨‍💻 Development Tools
VS Code for development
Expo Go for testing on physical devices
Chrome DevTools / React Native Debugger (optional)
